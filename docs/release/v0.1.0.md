# LocalReel 0.1.0 release notes

LocalReel is a local-first media server: one Rust binary, an embedded React UI,
SQLite state, ffmpeg for metadata/thumbnails/transcodes, and no cloud account.

## Highlights

- **Library / Reels / Player**: scan a directory, browse a grid, swipe a
  vertical feed, resume where you left off.
- **Admin**: health, sources, scan/job history, cache GC, backup export/import,
  one-click restore, source archive/remap.
- **Persistent jobs**: scans, probes, thumbnails, transcodes, GC and restore all
  survive restarts; progress/cancel via API/Admin.
- **Backups**: versioned JSON, merge-safe state, two-pass or one-command restore.
- **Windows**: portable zip, `install.ps1`/`uninstall.ps1`, per-user MSI,
  Task Scheduler helper.
- **Linux**: tarball + install scripts; WSL2 build, media playback and Chrome
  resume verified.
- **Docker**: multi-stage image + Compose; verified in WSL2 dockerd.

## Install

Windows portable:

```powershell
# extract the zip
.\install.ps1
# or: .\localreel.exe doctor; .\localreel.exe serve
```

Windows MSI:

```powershell
msiexec /i localreel-0.1.0-x64.msi
```

Linux:

```bash
tar -xzf localreel-0.1.0-x86_64.tar.gz
cd localreel-0.1.0-x86_64
./install.sh
```

Docker: see `docs/docker.md`.

## Requirements

- Windows 10/11 (primary) or Linux.
- ffmpeg/ffprobe on PATH, next to the binary, in `ffmpeg/bin`, or via
  `LOCALREEL_FFMPEG_DIR`. The Docker image bundles Debian ffmpeg.

## Known limitations

- Single-user and loopback-only; there is no authentication. Do not expose the
  port to untrusted networks.
- Windows is the primary target. Linux was verified under WSL2, not a bare-metal
  desktop; GPU/4K/HDR decode is not validated.
- HLS output, plugins/WASM and remote/NAS/S3 are out of scope for 0.1.
- Artifacts are unsigned; SmartScreen may warn.
- License: Apache-2.0 — see `LICENSE`. ffmpeg is not bundled, so its license
  depends on the build you install yourself.
