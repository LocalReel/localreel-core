# LocalReel 0.2.0 release notes

Faster playback for existing libraries, a UI that speaks Chinese, and a
cancellation path that actually stops work.

## Highlights

- **Chinese UI（中文界面）**: Library, Reels, Admin and the player are fully
  translated, with a 中文 / EN switch in the header of every page. The first run
  follows the browser language; the choice is remembered.
- **MKV plays in seconds**: H.264 files in MKV/MOV/TS/FLV/AVI are remuxed into
  MP4 (video stream copied, audio copied or re-encoded to AAC) instead of being
  re-encoded. Measured on this build: a 60 s H.264 clip with AAC audio remuxed in
  **0.5 s**, and one with FLAC audio (audio re-encoded only) in **2.1 s**.
- **Cancel really cancels**: the transcode process tree is killed on Windows and
  the job is finalized as `canceled` within a second; partial output is removed.
- **Thumbnails come first**: after a big scan the thumbnail jobs are no longer
  stuck behind tens of thousands of probes.

## Upgrade

```powershell
msiexec /x localreel-0.1.0-x64.msi
msiexec /i localreel-0.2.0-x64.msi
# or: extract localreel-0.2.0-x64.zip and run .\install.ps1
```

`data/` and `localreel.toml` are kept across install/uninstall. The database
migrations are forward-only; export a backup first (`Admin → Backup`) if the
library matters to you.

## Breaking/behaviour changes

- Transcode cache entries are keyed by preset name. Files transcoded by 0.1.0
  stay on disk until the scheduled cache GC, but a file may be processed again
  once under its new preset (`remux_h264*`), which is cheap for H.264 sources.
- A file that used to be re-encoded may now be remuxed; playback quality is
  unchanged, but the cache file name carries the `remux_h264` /
  `remux_h264_aac` preset.

## Known limitations (unchanged from 0.1.0)

- Single-user, loopback-only, no authentication.
- Windows-first; Linux verified under WSL2, not bare metal.
- HEVC, AV1 and other non-H.264 sources still need a full re-encode (slow).
- Artifacts are unsigned; SmartScreen may warn.

## Verification

- Rust: 73 tests (11 api + 33 kernel + 29 media), `clippy -D warnings`, `fmt`.
- Web: 12 unit tests (resume + i18n), `tsc` + `vite build`.
- Manual: dev instance on port 3101 with synthetic fixtures — direct play,
  remux (copy and copy+AAC), full re-encode, cancel mid-transcode, thumbnails.
- Packaged build: health `ok` on 0.2.0, `/` and `/admin` serve the embedded UI,
  and the shipped bundle contains the Chinese strings.
