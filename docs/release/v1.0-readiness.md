# v1.0 release readiness

Date: 2026-11-01
Version: 0.1.0
Target: Windows-first, local-only, single binary

## Decision

**Not ready for a public v1.0 release.** Personal/local use is ready and the
license question is now settled (Apache-2.0); public distribution is still
blocked by code signing and by the absence of a published release pipeline.
Do not tag `v1.0.0` until those are cleared.

## Release blockers

1. ~~**License is undecided.**~~ **Resolved 2026-11-02**: Apache-2.0 is the
   recorded decision. `LICENSE` exists in all three repositories and
   `Cargo.toml`/`package.json` declare the license.
2. **Code signing is absent.** SmartScreen will warn; MSI and zip are unsigned.
   A signing wrapper exists (`scripts/sign.ps1`) and a self-signed test proved
   embedded signatures on exe+MSI, but there is no CA-issued certificate yet.
3. **No published release pipeline.** The three repositories are tagged
   `v0.1.0` and live in the private `LocalReel` GitHub organization
   (`LocalReel/localreel-*`), but no CI job builds or publishes artifacts and
   there is no signed release manifest.

## Known limitations (acceptable for v0.1, document in release notes)

- Single-user, loopback-only; no authentication; remote binding requires
  `LOCALREEL_ALLOW_REMOTE=1` and an external trust boundary.
- Windows is the primary target; Linux is WSL2-verified, not bare-metal; no
  GPU/4K/HDR hard-decode validation.
- Docker was verified in WSL2 dockerd, not Windows Docker Desktop.
- Real-server browser resume test is a manual check; CI uses a mock server.
- ffmpeg fetch was verified against gyan.dev essentials 9.0.2 (hash checked,
  `ffmpeg -version`/`ffprobe -version`); there is still no pinned URL in-repo,
  because vendor builds move.
- Backup JSON is parsed directly from the file (no second raw byte copy), but
  the typed `Backup` (states Vec) still lives in memory; no incremental state
  streaming.
- HLS output is deferred to v1.1 by [ADR-010](../adr/010-hls-deferred.md);
  plugins/WASM, remote/NAS/S3 are out of scope for v1.
- MSI is per-user only; no machine-wide install or upgrade/rollback matrix.
